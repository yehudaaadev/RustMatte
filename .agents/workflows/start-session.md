# WORKFLOW: start-session

Description: Protocol to initialize a development session, restore context, and confirm the active task with the owner.

## Steps

1. Read `PROJECT_STATE.md` to restore session memory and active phase.
2. Read `docs/TASKS.md` for the current phase tasks.
3. Read `docs/PITFALLS.md` to refresh awareness of known traps.
4. Summarize the current project status and proposed next task in 5 lines or fewer.
5. Ask the owner for confirmation before modifying any code or files.
